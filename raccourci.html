Raccourci Apple Santé

Une seule fois, environ 20 minutes. Ensuite, sommeil, VFC, FC repos, poids et toutes tes séances arrivent seuls dans FTP Builder.

1Faire écrire toutes tes apps dans Santé

Le raccourci lit uniquement l'app Santé. Chaque app doit donc y écrire :

  • Apple Watch / Forme : rien à faire, c'est natif.
  • Garmin Connect (tes sorties Edge) : Plus › Paramètres › Applications connectées › Apple Santé › tout autoriser en écriture.
  • Strava : Vous › ⚙ Paramètres › Applications, services et appareils › Santé › connecter, activer « Envoyer les activités ».
  • Withings (Health Mate / Withings) : Profil › Applications partenaires › Apple Santé › activer.
  • Bevel : il lit Santé pour calculer ses scores, mais à ma connaissance ne les y réécrit pas. Ses données sources (sommeil, VFC…) sont donc déjà couvertes.
Vérifie dans Santé › ton profil (en haut à droite) › Apps que chaque app a bien les autorisations d'écriture cochées.

2Récupérer ta clé

  1. Dans FTP Builder : Profil › Apple Santé › Générer ma clé.
  2. Copie « Bearer ftpb_… » et garde-la sous la main (dans Notes, par exemple). Elle n'est affichée qu'une fois ; si tu la perds, régénère-la.
  3. L'adresse d'envoi est toujours la même :
    https://jhemwfhmohqncywjixgh.supabase.co/functions/v1/health-ingest

3Créer le raccourci

App Raccourcis › onglet Raccourcis › + › nomme-le FTP Builder Santé. Il a 3 parties, à construire dans l'ordre.

Partie A · Les mesures du jour

Pour chaque ligne du tableau, ajoute ces 2 actions :

  1. Rechercher des échantillons de santé → touche « Type » et choisis la mesure. Ajoute le filtre Date de début › la période indiquée. Pour les lignes « plus récent », règle aussi Trier par : Date de début, Ordre : Plus récent d'abord, Limite : 1.
  2. Calculer les statistiques → choisis la statistique indiquée. Puis touche le résultat « Statistiques » de l'action › Renommer avec la clé du tableau (ex. hrv) : ce sera plus facile à retrouver à l'étape suivante.

Commence par les 3 essentiels pour tester, puis ajoute les autres. Le nom exact d'une mesure peut varier un peu selon la version d'iOS : tape le début dans la recherche de « Type ».

Ajoute ensuite l'action d'envoi :

  1. Date actuelle, puis Formater la date → Format de date : Personnalisé, chaîne yyyy-MM-dd.
  2. Obtenir le contenu de l'URL :
    • URL : l'adresse de l'étape 2.
    • Touche Afficher plus › Méthode : POST.
    • En-têtes › Ajouter : clé Authorization, valeur ta clé « Bearer ftpb_… ».
    • Corps de la requête : JSON. Ajoute des champs de type Texte : kind = daily ; date = la « Date formatée » ; puis un champ par mesure, avec la clé du tableau et, en valeur, la variable renommée correspondante (ex. hrv = variable « hrv »).

Partie B · Le sommeil

  1. Rechercher des échantillons de santé → Type Analyse du sommeil, Date de début dans les 1 derniers jours, sans limite.
  2. Répéter avec chacun (sur ces échantillons).
  3. À l'intérieur : appui long sur l'action d'envoi de la partie A › Dupliquer, puis glisse la copie dans la boucle (l'URL et la clé sont déjà remplies). Remplace les champs du corps par :
    • kind = sleep
    • start = Élément répété › touche-le › Date de début › Format de date ISO 8601, inclure l'heure.
    • end = Élément répété › Date de fin (ISO 8601, avec l'heure).
    • stage = Élément répété › Valeur (Au lit, Essentiel, Profond, Paradoxal, Éveillé…).
    • source = Élément répété › Source.

Si plusieurs apps enregistrent ta nuit (montre, Withings, Bevel…), FTP Builder garde la plus complète, en priorité l'Apple Watch.

Partie C · Les entraînements (montre, Strava, Garmin Connect…)

  1. Rechercher des échantillons de santé → Type Entraînements, Date de début dans les 2 derniers jours.
  2. Répéter avec chacun, et à l'intérieur une copie de l'action d'envoi avec ces champs :
    • kind = workout
    • start / end = Élément répété › Date de début / Date de fin (ISO 8601, avec l'heure).
    • type = Élément répété › Type (ou « Type d'entraînement »).
    • duration = Élément répété › Durée.
    • distance = Élément répété › Distance, si la propriété est proposée.
    • energy = Élément répété › Énergie (active ou totale), si elle est proposée.
    • source = Élément répété › Source.

Une même séance vue par Strava, Garmin Connect et la montre n'est comptée qu'une fois. Tes sorties vélo déjà importées en .fit ne sont pas doublées non plus.

4Premier essai

  1. Pour le test, ajoute à la toute fin une action Afficher le résultat sur le résultat de la partie A.
  2. Touche ▶︎ pour lancer. iOS demande l'accès à Santé : active toutes les catégories. Il demande aussi l'autorisation de contacter « supabase.co » : Toujours autoriser.
  3. Tu dois voir une réponse du type {"ok":true,"daily":3,…}.
  4. Dans FTP Builder, va dans Profil › Apple Santé › Actualiser : « Dernier envoi » se met à jour et la carte Forme du jour apparaît sur Aujourd'hui.
  5. Une fois que ça marche, supprime l'action « Afficher le résultat ».
Erreur Clé invalide : recopie la clé avec « Bearer » et un espace devant. Erreur réseau : vérifie la méthode POST et l'adresse.

5L'automatiser

Raccourcis › onglet Automatisation › + :

  1. Heure de la journée › 21:30 › Quotidien › Exécuter immédiatement (désactive « Notifier lors de l'exécution ») › choisis FTP Builder Santé. Il récupère les totaux de la journée et tes séances.
  2. App › choisis une app que tu ouvres chaque matin (Forme, Bevel, Strava ou Mail) › Est ouverte › Exécuter immédiatement › même raccourci. Il récupère ta nuit, ta VFC et ton poids du matin.
Pourquoi l'app du matin plutôt qu'une heure fixe ? iOS protège les données Santé tant que l'iPhone est verrouillé. Un raccourci lancé à 7 h pendant que le téléphone dort dans ta poche ne peut pas les lire. À l'ouverture d'une app, l'iPhone est forcément déverrouillé. Tu peux relancer le raccourci autant de fois que tu veux : les données sont mises à jour, jamais dupliquées.

Tes données Santé sont stockées dans ton compte FTP Builder (Supabase, Paris), visibles par toi seul. Politique de confidentialité.
